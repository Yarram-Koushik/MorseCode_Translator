# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within **Morse Signal Lab**, please report it responsibly:

1. Do **NOT** open a public issue.
2. Email the maintainer directly at `yerramkoushik4@gmail.com` with:
   - Detailed description of the vulnerability.
   - Steps to reproduce or proof-of-concept.
   - Potential impact assessment.
3. We will acknowledge receipt within 48 hours and coordinate a security fix.

Thank you for keeping Morse Signal Lab secure!

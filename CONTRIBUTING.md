# Contributing to Morse Signal Lab

Thank you for your interest in contributing to **Morse Signal Lab**! 🎉

## How to Contribute

1. **Fork the Repository**
2. **Create a Feature Branch**
   ```bash
   git checkout -b feat/your-feature-name
   ```
3. **Make your Changes & Run Tests**
   ```bash
   pytest -v
   cd frontend && npm run build
   ```
4. **Commit Your Changes**
   ```bash
   git commit -m "feat: describe your change"
   ```
5. **Push to Your Branch & Open a Pull Request**
   ```bash
   git push origin feat/your-feature-name
   ```

## Contribution Guidelines

- **Code Quality**: Ensure all code is cleanly formatted with TypeScript/Python type annotations.
- **Tests**: Add unit tests in `backend/tests/` for new endpoints or algorithms.
- **Documentation**: Keep the README and API specifications updated.

Thank you for helping make Morse Signal Lab better!
